# Reference comparison — 12 November 2026

TaskDesk compared with Plane, Kaneo (upstream), Jira, Jira Service Management, OpenProject, Zendesk, Freshdesk/Freshservice, Zammad, the ServiceNow customer-portal pattern and Linear (design). Done for Thomas on 12 Nov. Eight Sonnet researchers read product documentation and the TaskDesk code; an Opus reviewer wrote the comparison; a second Opus reviewer checked it, and its corrections are applied below. Items already in the [plan](../plan.md) carry their plan id.

**Limits:** product facts come from public documentation, not from using the products. Several reference details could not be confirmed from a source and were treated as common knowledge. TaskDesk facts come from reading the code on `main` (31c91af75), not from a browser.

## Short answer

- **Breadth:** TaskDesk already has more than Plane, Kaneo or OpenProject, and is close to Jira Service Management on ticketing depth (versioned workflows, SLA calendars, approvals, knowledge-base suggestions).
- **Where it is behind:** polish and consistency, and the 12 Nov owner decisions that are not in code yet.
- **Common pattern in every reference:** projects are private and invite-only; customers see only their own requests unless sharing is switched on; public reply and internal note are clearly separate; statuses sit in a few fixed groups with editable names. TaskDesk should follow that pattern.
- **Do not copy:** public projects with self-join (Plane), anonymous and non-member roles (OpenProject), open request raising (Jira Service Management), permission and workflow schemes (Jira).
