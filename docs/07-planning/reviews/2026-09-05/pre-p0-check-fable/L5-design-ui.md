## Top 5

1. **The Radix/Base UI contradiction is repo-wide, not a typo.** design-system.md:10 & :85, definition-of-done.md:60, accessibility.md:12/:21/:143 and ADR 0008:26-27/:58 all instruct "use Radix" / credit accessibility to Radix, while ui-extraction-plan.md:16 makes Base UI the standard and `check:ui` **fails the build** on unlisted Radix. An agent handed the DoD will do exactly what CI rejects. Fix all five files together, and amend or supersede ADR 0008.
2. **There is no Radix migration to do — the extraction plan is sized for work that does not exist.** 17 of kaneo's 18 `@radix-ui/*` deps have **zero** references in `apps/web/src`; the only live usage is `Slot` in form.tsx:3 and (via the undocumented `radix-ui` umbrella package) timeline.tsx:3. `KNOWN-RADIX.md` starts with one entry at most; the 17 dead deps must simply not be copied.
3. **Most of design-tokens.md does not describe kaneo.** Base scale is **neutral**, not zinc (`--zinc` count = 0); all four radius values are wrong (real: 6/8/10/14px from `--radius: 0.625rem`); both easing curves are wrong; `--color-danger` does not exist (it is `--destructive`); and `--space-*`, `--z-*`, `--text-*`, `--shadow-*` and the layout tokens exist **nowhere** in kaneo — they are new work presented as extraction. G3 is also not scriptable as written, because kaneo's tokens are `--alpha()`/`color-mix()` values that need resolving and compositing.
4. **G12 (portal bundle purity) cannot pass on the inherited architecture, and no doc describes the fix.** kaneo has one `index.html`, one `main.tsx` and one generated `routeTree.gen.ts` with 49 static route imports; `grep -rn routeTree docs/` = 0 hits. "Two entries, one source" needs two `tanstackRouter()` instances with separate `routesDirectory`/`generatedRouteTree` and two rollup inputs — an undocumented routing split, not a build flag.
5. **Three gates are prose wearing an "Automated" heading: G8 (no visual-regression tool named anywhere — "Chromatic-style" is an adjective), G13 (no windowed-CLS mechanism), and the deciding half of G6 ("meaningful" is a human judgement).** Also G11's INP and "60 fps, no dropped frames" rows are unmeasurable in CI while being declared merge blockers. Good news: **G9 is properly wired** to the reduced-motion Playwright project at testing-strategy.md:237, and the screen-inventory phase counts sum correctly to 136 — no defect there.
