# TaskDesk

A self-hostable, multi-tenant service desk and work-management platform built on Kaneo.
Original Kaneo interface, real persisted features, one configurable image.

See the [whole-product features](docs/features.md) and [full roadmap](docs/roadmap.md). Start with [the current docs](docs/README.md). Contributors follow [AGENTS.md](AGENTS.md).

```sh
pnpm install
pnpm dev
```

Local development needs the API environment and PostgreSQL configured; see [testing](docs/testing.md).
